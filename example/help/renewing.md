# Renewing a loan

<!-- ont: action.renew@3a0bfa, rule.renewal@ee5883, field.loan.renewals@d73680 -->
## How renewal works

If you need an item longer, renew it from "My loans". Each renewal adds 14 days to the current due date. A loan can be renewed twice; the list shows how many renewals you have used.

<!-- ont: inv.no-renew-when-held@58bed4 -->
## When renewal is refused

You cannot renew an item while another member is waiting for the same title. The renew button stays visible and tells you that someone is waiting, so you know why. Bring the item back by its due date; the next member gets it.
