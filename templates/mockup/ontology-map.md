# UI-to-ontology map

Each meaningful element of the mockup, what it shows and the concept behind it. What an element deliberately does not do is behavior and is written in the ontology. The check verifies that this map and the mockup contain the same IDs.

## Thing page

| Element | ID                  | What it shows    |
| ------- | ------------------- | ---------------- |
| Page    | `view.thing.page`   | one thing        |
| "State" | `field.thing.state` | open or closed   |
| "Close" | `action.close`      | closes the thing |
