# UI-to-ontology map

Each meaningful element of the mockup, the concept behind it, what it shows and what it deliberately does not do. The check verifies that this map and the mockup contain the same IDs.

## Thing page

| Element        | ID                | What it shows        | What it does not do                 |
| -------------- | ----------------- | -------------------- | ----------------------------------- |
| Page           | `view.thing.page` | one thing            |                                     |
| "State"        | `field.state`     | open or closed       | not editable by hand                |
| "Close"        | `action.close`    | closes the thing     | no "Reopen" anywhere (D-01)         |
