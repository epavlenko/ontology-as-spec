## A first-time user can tell how to close a thing

Start in the mockup, `mockup/index.html`, opened from the file system in a browser, on the screen that shows an open thing.

1. Take a screenshot of the screen as it shows, or copy its text.
2. **Fresh reader.** Give a fresh reader, a model without context, only what a first-time user would see: the screenshot or the text of the screen, and nothing else, not the ontology, not the catalogue. Ask it how it would close the thing.
3. Read its answer against the check's THEN: it names the element that closes the thing, without help. An answer that needs more than the screen is a fail, named with what was missing.

Keep, named by the check's ID and the date: the screenshot or the text, what the fresh reader was given, and its answer.

Traps:

- The reviewer answering for the user proves nothing: it has read the ontology.
