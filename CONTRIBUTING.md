# Contributing

Ontology as Specification is an early version, v0.1, in active development: the rules still change every few days, each with an entry in [decisions.md](decisions.md). See [Status and origin](README.md#status-and-origin).

- **Issues are open** for questions and for reports of errors: a check that passes where it should fail or fails where it should pass, a rule that the documentation states one way and the tool enforces another, an example that does not run. Say which file it is about and, for the tool, the command and its output.
- **Pull requests are not accepted yet,** and they are switched off for this repository. There is no process to review outside changes, and while the rules move this fast a change would be outdated before it was reviewed. Describe a change you would propose in an issue instead.

Whether and when outside contributions are accepted is a later decision ([D-46](decisions.md)).
